# T3.6b — Dọn worktree (M, sau pilot)

Tách đóng phiên khỏi dọn checkout. Chỉ dọn checkout do server tạo sau khi lượt ghi dừng và các phiên liên quan đã đóng hoặc được gỡ liên kết. Kiểm tra staged, unstaged, untracked, file ignored có dữ liệu local và commit chưa được branch bền vững giữ. Nếu đủ điều kiện, dùng `git worktree remove` thông thường và giữ branch. Dọn tự động chỉ xem xét sau khi luồng dọn thủ công đã được kiểm chứng.
