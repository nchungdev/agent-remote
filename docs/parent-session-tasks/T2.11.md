# T2.11 — Usage và quota (M)

Lưu `EvUsage` theo lượt và session con, phân biệt snapshot context mới nhất với số token theo lượt (input, output, cache đọc/ghi). Tổng session cha chỉ cộng số liệu theo lượt, gồm cả consult, khử trùng khi replay; ghi rõ phần thiếu dữ liệu. Lấy quota qua `QuotaProvider` theo phạm vi tài khoản/nhà cung cấp do adapter trả về, kèm thời điểm cập nhật và thời điểm reset nếu có. Dữ liệu thiếu hoặc quá hạn có trạng thái riêng; các giá trị mặc định theo tên model ở legacy không đi vào luồng mới.
**Xong khi:** test replay không cộng trùng, snapshot context không bị cộng vào tổng, thiếu dữ liệu khác 0%.
Lỗi `quota_exceeded` chỉ phát gợi ý. Thay nhận dạng lỗi dựa trên chuỗi bằng fixture T0.4 khi có thể.
