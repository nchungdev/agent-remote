# T4b.4 — Plan, review và artifacts (L)

Dùng chung card kế hoạch, bước chờ duyệt, kết quả test và review diff theo mốc checkout. Review dùng luồng chỉ đọc đã kiểm chứng. Adapter có thể ánh xạ native plan/review/artifact sang card chung; với engine chưa có event tương đương, dùng kết quả có cấu trúc đã validate và nguồn file/diff do server cấp. Lưu artifact và feedback theo phiên cha để agent khác có thể tiếp tục từ cùng nguồn.
