# T4.7a — Chọn checkout cho phiên mới (M)

Sau khi chọn repo, cho chọn **Dùng checkout hiện tại** hoặc **Tạo worktree riêng**. Với checkout hiện tại, hiện phiên đang chạy lượt ghi nếu có. Với worktree mới, chọn branch nguồn, xem commit bắt đầu và ghi rõ thay đổi chưa commit ở lại checkout nguồn. Header hiển thị tên branch/checkout cạnh writer, giữ checkout khi chuyển agent. Sau khi tạo, báo dependency hoặc cấu hình local bị thiếu nếu phát hiện được, gồm `shared/remote-tunnel` và `app/local.properties` trong kiểm chứng trên repo này.
