# T4.5 — Writer và model (M)

Một chip **Đang làm · Agent** ở header chat, mở menu xem agent trong phiên hoặc chọn **Chuyển lượt**. Composer giữ bộ chọn model/effort của writer hiện tại theo capability. Điện thoại dùng sheet cho danh sách agent, desktop dùng menu. Writer rảnh thì chuyển ngay sau khi chọn, trừ lần đầu gửi ngữ cảnh cho agent đó. Writer đang chạy thì hộp thoại có **Tiếp tục lượt hiện tại** và **Dừng và chuyển**; chờ server xác nhận hủy trước khi chuyển. Giữ draft và khóa gửi prompt thường trong lúc chuyển. Chỉ đổi chip khi có kết quả từ server; nếu thất bại, hiện lý do và giữ draft để thử lại.
**Xong khi:** đổi model giữ nguyên writer, bấm chuyển hai lần chỉ tạo một lần chuyển, và gửi sau chuyển đi đúng session con. Xác nhận lần đầu nêu nhà cung cấp đích, loại dữ liệu được gửi và chi phí token phát sinh.
