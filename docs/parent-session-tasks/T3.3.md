# T3.3 — Protocol session (M)

Thêm action `SESSION_CREATE`, `SESSION_LIST`, `SESSION_GET`, `SESSION_SEND`, `SESSION_SWITCH_WRITER`, `SESSION_CONSULT`, `SESSION_FORWARD_CONSULT`, `SESSION_IMPORT`, `SESSION_DECIDE`, `SESSION_CANCEL`. Thêm event `SESSION_EVENT` có `parentSessionId`, `seq`, và `features: ["sessions_v2"]` trong `SESSION_INIT`. Giữ nguyên action cũ. `SESSION_INIT.sessionId` giữ nghĩa ID kết nối hiện tại; payload mới dùng `parentSessionId` cho ID phiên cha (kể cả `SESSION_EVENT`). Cùng một bộ khả năng trên WebSocket và WebRTC, kể cả sau chuyển transport. Ghi rõ response, lỗi có kiểu, cursor phân trang và khóa idempotency cho action tạo lượt, chuyển writer, chuyển tiếp và duyệt; `SESSION_CANCEL` chỉ rõ lượt hoặc toàn phiên.
**Xong khi:** có tài liệu protocol và test tuần tự hóa; app cũ vẫn chạy được.
