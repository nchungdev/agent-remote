# T2.4a — Định danh checkout và quyền thực thi (M)

SQLite lưu checkout (`checkoutId`, `repositoryId`, root chuẩn hóa, Git dir, branch hoặc detached HEAD, base SHA, nguồn và trạng thái), phiên cha gắn `checkoutId`, lượt ghi gắn checkout, turn, agent và revision. Server dùng `git rev-parse`, canonical path và `git worktree list --porcelain -z` để hợp nhất alias qua thư mục con/symlink. Worktree cùng repo dùng chung `repositoryId` và có `checkoutId` riêng. Writer lease theo checkout áp dụng cho mọi đường dispatch legacy/v2 trên host quản lý. Sau khi writer cũ và tool con đã dừng, đọc lại Git trước khi dispatch writer mới; nếu chưa xác minh được, giữ chặn và hiển thị **Cần xác minh**. Thay đổi từ IDE/CLI bên ngoài được xử lý như workspace drift.
**Xong khi:** hai client mở cùng checkout qua hai đường dẫn chỉ chạy được một lượt ghi; chuyển A → B → A giữ nguyên staged, unstaged và untracked.
