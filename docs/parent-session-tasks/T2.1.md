# T2.1 — Mô hình dữ liệu (M)

Ánh xạ conversation thành session cha, binding thành session con. Thêm vào event: `turn_id`, `origin_engine`, `requested_by`, `purpose` (`work` hoặc `consult`). Thêm vào binding: `model`, `effort`, `role`, `native_mtime`. Migration chỉ thêm cột, có giá trị mặc định.
**Xong khi:** test migration trên DB cũ và DB trống; mở DB đã migrate bằng code cũ không hỏng dữ liệu, hoặc ghi rõ cần sao lưu.
