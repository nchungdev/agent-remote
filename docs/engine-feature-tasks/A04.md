# A04 — Adapter Antigravity

## Công việc

Antigravity. So sánh ACP và headless stream trên bản pin. Ánh xạ project/conversation vào checkout, xử lý soft-deny và usage tích lũy.

## Tiêu chí nghiệm thu

Cùng suite về resume, approval, hủy, read-only và worktree. V2 dùng mode đã kiểm chứng quyền. Kiểm tra context/quota, model local và Stick message riêng theo phiên bản.
