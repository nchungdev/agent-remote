# A03 — Adapter Claude Code

## Công việc

Claude Code. So sánh print stream với Agent SDK streaming trên bản pin. Tích hợp resume, UUID message, permission callback, câu hỏi, usage và trạng thái compact nếu có.

## Tiêu chí nghiệm thu

Hai lượt liên tiếp, restart/resume, từ chối tool, hủy khi đang ghi và worktree qua cùng suite. Tái hiện fork theo UUID và kiểm tra fast mode nếu hỗ trợ.
