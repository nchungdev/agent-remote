# A01 — Hợp đồng adapter và fake engine

## Công việc

Chốt hợp đồng adapter và fake engine. Chuẩn hóa WorkspaceRef, native session/turn ID, stream, kết quả terminal, approval, quota và capability.

## Tiêu chí nghiệm thu

Fake tái hiện được mất kết nối, dispatch chưa rõ kết quả, tool ghi chậm, approval và event đến muộn.
